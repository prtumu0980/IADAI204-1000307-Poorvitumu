IPL Cricket Data Analysis – Decoding Match-Winning Factors
Project Overview

This project analyses IPL cricket data to identify key match-winning factors, player performances, and team rivalries using Tableau. The dashboard provides interactive insights for coaches, franchises, broadcasters, and fans.

Data Summary

The dataset consists of:

matches.csv (match-level data)

deliveries.csv (ball-by-ball data)

The two datasets were connected using:
matches.id = deliveries.match_id

Data cleaning involved handling missing values and ensuring team name consistency.

Key Insights

Top batters were identified based on total runs and strike rate.

Leading bowlers were analysed using wickets and economy rate.

Toss decisions impact match outcomes in certain seasons.

Venue analysis shows strong home-ground advantage trends.

Team rivalry patterns highlight dominant franchises.

Dashboard Features

Interactive filters for season and team.

Player performance analysis (batting and bowling).

Toss and venue impact analysis.

Dynamic charts allowing drill-down exploration.

Conclusion

The dashboard demonstrates how player performance metrics and contextual factors such as toss decisions and venues influence IPL match outcomes. Future improvements could include advanced predictive modelling and deeper over-wise analysis.

The dataset used for this project consists of matches.csv and deliveries.csv.
